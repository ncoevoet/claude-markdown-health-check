## Already covered / no action

- Skill name/description limits (64 / 1024, XML tags, reserved words `anthropic`/`claude`) from platform `agent-skills/overview`: already `BAD-NAME`, `DESC-XML-TAG`, `RESERVED-WORD-PORTABILITY`, `DESCRIPTION-TOO-LONG`.
- Skill-listing budget (1% of context, 8,000-char floor, 1,536 per entry, `disable-model-invocation` excluded and not re-injected after `/compact`): `skill-listing-budget.md`. The context-window page agrees; only the compaction cap (row 10) is new.
- MEMORY.md "first 200 lines or 25KB": `MEMORY-OVERFLOW` already. CLAUDE.md "under 200 lines" and "bloated files get ignored" (`best-practices`, `claude-directory`): covered by CLAUDE.md quality scoring and context-engineering checks. Emphasis on many lines is covered by the shouted-absolutes check.
- Hook exit 1 vs 2 (`hooks`, `debug-your-config`): `HOOK-EXIT-NONBLOCKING`. Hooks in a standalone file instead of `settings.json`: partially covered by `UNREGISTERED-HOOK`.
- Plugin `userConfig` in shell commands, `./` path prefix, semver version, dependencies, `strictKnownMarketplaces`, deprecated `sse` transport, http hook allowlist: all present in `plugin-integrity.md` and `hook-safety.md`.
- `skillOverrides`, `claudeMdExcludes`, `autoMemoryDirectory`, `background:` skill frontmatter, `context: fork`: already in the known-field/key lists.
- Weekly changelogs w30-w37 (new default model, auto mode default, fork mode, Restricted mode, `modelPicker`, `promptCacheTtl`, `maxEffortLevel`, `managedMcpServers`, `modelPricing`, `CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS`, desktop and VS Code features): behaviour or managed-only keys with no static-audit angle beyond row 5. `/skill-doctor` (w36) overlaps the Skill usage phase; cite it as a runtime cross-check, do not reimplement.
- `agents`, `agent-teams`, `managed-settings`, `plugins/dependencies`, `plugins/loading`, `plugins/security`, `plugins/relevance`: read; nothing statically checkable beyond existing tags. Possible low-value extras: `relevance` limits in `marketplace.json` (topic 64 chars, 10 signal patterns of 256, "a recognized field whose value exceeds its limit ... invalidates the whole plugin entry"); `.claude/workflows/*.js` is a new component the auditor never inspects (a symlinked `.claude` or `workflows/` is refused by the save path); a plugin `dependencies` version range must be tagged `<name>--v<semver>` in git.
- Platform `claude-prompting-best-practices` and `prompting-claude-opus-5-5`: advice targets API integrations (effort, `max_tokens`, thinking blocks). The only transferable item is "remove instructions that stood in for thinking" ("think carefully", "write out your reasoning") in CLAUDE.md or skill bodies. `git grep -i -e 'think carefully' -e 'step by step' -- plugin` is empty, so it could be a judgment-only idea in `body-compression.md`, value low.
